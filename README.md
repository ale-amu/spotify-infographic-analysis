# Spotify Audio Features — Exploratory Data Analysis
**DS 2023 Final Project | University of Virginia**

## Overview
A three-part exploratory data analysis of the Ultimate Spotify Tracks Dataset, examining how audio features like danceability, energy, and popularity vary across genres. The project walks through data acquisition, feature exploration, and visual storytelling using Python.

---

## Notebooks

### Notebook 1 — Data Acquisition & Structure
- Loaded and inspected the Spotify audio features dataset from Kaggle
- Documented 18 features including danceability, energy, valence, tempo, loudness, and popularity
- Handled missing values and established data types for downstream analysis

### Notebook 2 — Exploratory Data Analysis
- Analyzed the distribution of track popularity — found most tracks cluster in the mid-range with viral hits being relatively rare
- Visualized genre frequency across the dataset
- Explored relationships between danceability, energy, valence, and genre using histograms, bar charts, and Seaborn visualizations

### Notebook 3 — Infographic & Insights
- Synthesized findings into a final visual narrative
- Communicated key patterns in audio features across genres
